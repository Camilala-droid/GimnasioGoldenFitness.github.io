Golden Fitness V3 es un sistema académico semi-profesional desarrollado con PHP MVC + MySQL + CSS/JS propio.

Objetivo: mantener código entendible para estudio, pero con una interfaz y flujo de trabajo cercanos a un sistema real.

Consultar README_V3.txt para instalación y AUDITORIA_SISTEMA_REFERENCIA.md para conocer qué se aprovechó del sistema de referencia.
