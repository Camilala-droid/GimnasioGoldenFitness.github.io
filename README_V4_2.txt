GOLDEN FITNESS V4.2 - CORRECCIÓN DE FLUJOS

MEJORAS DE CLIENTES
- Clientes existentes ahora tienen acciones visibles: Ficha, Editar/Foto, Membresía y Activar/Desactivar.
- Editar permite cambiar datos y subir/reemplazar fotografía de un cliente ya creado.
- La ficha del socio también incluye Editar/Cambiar foto y Activar/Desactivar.
- Un cliente INACTIVO no puede recibir nuevas membresías ni nuevas reservas hasta ser reactivado.
- No se elimina al cliente: se conserva su historial y se usa estado ACTIVO/INACTIVO.

MEJORAS DE CLASES
- Se reemplazó el formulario visual antiguo por un editor V4.2.
- El editor separa datos de la actividad, categoría, estado y entrenador.
- El entrenador seleccionado muestra fotografía, nombre, especialidad, descripción y teléfono.
- Al editar una clase se muestran sus horarios actuales y acceso directo a crear otro horario.
- Al crear una clase nueva, al guardar se continúa directamente a crear el primer horario.
- La lógica sigue siendo MVC: ClaseController -> Clase Model -> vistas.

BASE DE DATOS
- No se agregaron tablas nuevas en esta corrección.
- Compatible con la base V4.1.
